# **App Name**: Squadron Manager

## Core Features:

- Meeting Logger: Allow users to record and document meeting minutes, including action items and decisions.
- Data Exporter: Enable the export of reports in PDF or Excel format for meetings, actions, audits, staff, and training records.
- Training Overview: Provide a straightforward interface for Squadron Executives to record staff training and accomplishments and produce reports.
- Professional Development Planning: Straight forward interface to create and export a professional development plan for a staff member
- Discipline Actions: Form to record and write records of conversation and note any serious breaches of code of conduct
- Safety Audits: Ability to perform safety inspections documenting hazards and record information (including photos) and create action items for rectification.
- Staff Compliance Form: Form that captures a staff members compliance with mandatory training and compliance items.

## Style Guidelines:

- Primary color: Use a shade of blue (#00308F) to represent the Australian Air Force.
- Secondary color: Use a light grey (#D3D3D3) to provide contrast against the primary color.
- Accent: Use yellow (#FFDA63) for interactive elements and important information.
- Employ a clean and structured layout to ensure ease of use and navigation.
- Use clear and representative icons for each module and function within the application.
- Subtle animations or transitions when navigating between sections to provide a smooth user experience.
